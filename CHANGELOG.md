# Изменения Sonat для Mac

## 0.5.2 — 23 ноября 2026

Исправлена обработка файлов приложения при обновлении. Sonat повторяет попытку очистить временную папку, если она занята. Если обновление прервалось, сообщение об ошибке сохраняет причину сбоя. Для перехода со старой версии после ошибки `ENOTEMPTY` в руководстве есть способ замены приложения через Finder.

Сборки для Apple Silicon и Intel прошли установку и проверку обновления внутри Electron. Пользователь подтвердил работу приложения на своём Mac после перехода на эту версию. [Скачать 0.5.2](https://github.com/StepanCyberPsy/Sonat/releases/tag/v0.5.2) · [Результаты проверки](https://github.com/StepanCyberPsy/Sonat/actions/runs/45218428029) · [Инструкция по обновлению](README.md#обновление)

## 0.5.1 — 23 ноября 2026

В строке меню macOS появился значок S. Через него можно открыть окно Sonat и установить доступное обновление. Проверка выполняется при запуске и каждые четыре часа. [Релиз 0.5.1](https://github.com/StepanCyberPsy/Sonat/releases/tag/v0.5.1)

## 0.5.0 — 23 ноября 2026

Sonat предлагает записать звонок, когда распознаёт его по работе аудиоустройств или заголовку окна встречи. Предложение доступно и при выключенной камере. Запись начинается после нажатия «Записать». [Релиз 0.5.0](https://github.com/StepanCyberPsy/Sonat/releases/tag/v0.5.0)
