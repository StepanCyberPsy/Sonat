# Sonat

Sonat для macOS 14.2 и новее записывает звонок или голосовую заметку. В режиме «Звонок» он берёт ваш голос с микрофона и звук собеседников из системы, в том числе при звонке в наушниках. Подходит для Zoom, Google Meet в браузере и других программ. В запись попадут и другие звуки компьютера, например уведомления. Режим «Диктофон» использует только микрофон.

## Установка на Mac

1. Скачайте и распакуйте [Sonat для Mac](https://github.com/StepanCyberPsy/Sonat/archive/refs/heads/main.zip) и дважды нажмите **Установить Sonat.command**. Для загрузки Electron нужен интернет. Установщик сверяет контрольную сумму загрузки, собирает приложение в вашей папке «Программы» и открывает его. Поддерживаются Apple Silicon и Intel.
2. Нажмите **Выбрать папку** и укажите, где хранить тексты.
3. Для автоматической расшифровки создайте ключ проекта в личной организации, куда начислены кредиты. Введите его в разделе **Настройки → Авторасшифровка** и нажмите **Сохранить и включить**. Ключ хранится на Mac в зашифрованном виде. [Ключи API](https://platform.openai.com/api-keys).
4. Выберите **Звонок** или **Диктофон** и нажмите **Начать запись**. При первом запуске разрешите микрофон, а для звонка — захват экрана и системного звука. Разрешения доступны в «Системные настройки → Конфиденциальность и безопасность». Если macOS попросит перезапустить Sonat, сделайте это до звонка.
5. Скажите несколько слов и проверьте индикатор микрофона. Когда говорит собеседник, должен двигаться индикатор «Звук компьютера». Нажмите **Остановить запись**. При включённой авторасшифровке Sonat отправит аудио в OpenAI и сохранит готовый текст рядом с папкой «Аудио Sonat». При ошибке запись останется в списке ожидающих. Нажмите **Расшифровать**, чтобы продолжить с первой несохранённой части.

### Вручную через чат

При отключённой авторасшифровке Sonat покажет первую часть записи.
1. Нажмите **Показать WAV в Finder** и **Открыть ChatGPT**. Войдите в свой аккаунт с подпиской. В обычном чате выберите GPT‑6 Instant, если он доступен, перетащите выделенный WAV и попросите дословную расшифровку. Кнопка **Скопировать запрос** подготовит текст просьбы.
2. Скопируйте ответ ChatGPT, вставьте его в Sonat и нажмите **Сохранить часть**. После последней части Sonat автоматически положит один файл .txt в выбранную папку.

У установщика и приложения нет нотариального заверения Apple. Если macOS блокирует открытие загруженного файла, для доверенной копии используйте кнопку «Всё равно открыть» в настройках конфиденциальности и безопасности.

## Подписка OpenAI

В автоматическом режиме Sonat использует модель OpenAI `gpt-transcribe`. Запросы расходуют кредиты привязанной API-организации. Если они закончатся, OpenAI может использовать купленный баланс. [Баланс и начисления](https://platform.openai.com/settings/organization/billing/overview).

В ручном режиме распознавание выполняется в вашем чате ChatGPT. Ключ API и отдельный баланс API не требуются. Файлы вы прикрепляете сами. OpenAI указывает лимит до шести минут на одно вложение и зависимость доступа от тарифа, региона и клиента. Sonat готовит WAV длительностью до четырёх минут. Вход через ChatGPT для сторонних приложений пока не поддерживает аудио и программную расшифровку. [Аудиофайлы в ChatGPT](https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt) · [Ограничения входа через ChatGPT](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations).

## Горячая клавиша

Пока приложение запущено, **Control + Option + R** запускает запись в выбранном режиме. Повторное нажатие останавливает её. При запуске записи сочетанием Sonat выводит окно на передний план для доступа к захвату звука. Сочетание работает и когда вы находитесь в Zoom или браузере.

Для изменения нажмите **Настройки** или **⌘,**. В разделе «Горячая клавиша записи» нажмите **Изменить** и введите сочетание с буквой или цифрой. Допустимы Command, Option, Control и дополнительный Shift. Если сочетание занято, Sonat предложит выбрать другое. Кнопка **Отключить** освобождает горячую клавишу.

## Где лежат файлы

При первом запуске выберите папку в Finder. На главном экране виден её полный путь, **Открыть в Finder** открывает именно её. Например, если выбрать локальную папку `~/Music/Sonat`, текст появится в `~/Music/Sonat/<имя записи>.txt`, а исходный звук — в `~/Music/Sonat/Аудио Sonat/<имя записи>/part-000001.wav`. Имя записи включает дату и время. Если выбрать сетевой диск или синхронизируемую папку, хранение и копирование зависят от этого места.

Sonat не ведёт архива на сервере разработчика. При включённой авторасшифровке приложение передаёт WAV с Mac напрямую в OpenAI. Исходные WAV остаются в выбранной папке. Один час занимает примерно 115 МБ, 200 часов — около 23 ГБ (моно, 16 кГц, 16 бит).

## Аудио и повторная расшифровка

Запись запускается вручную. Во время разговора Sonat пишет звук на диск. Аудио хранится в подпапке «Аудио Sonat» рядом с текстами. Длинная запись состоит из четырёхминутных WAV-файлов в порядке разговора. Открыть их можно в обычном проигрывателе. Окно Sonat можно свернуть.

Можно нажать **Продолжить позже**, затем открыть ту же папку и выбрать запись из списка ожидающих. Sonat помнит каждую сохранённую часть. После аварийного закрытия тот же порядок восстанавливает заголовок последнего записанного WAV.

## Для разработки

Исходники — в `app/`. Для проверок нужен Node.js 24: `npm test`. Установка на Mac использует закреплённую версию Electron и штатные средства macOS. Для проверки разрешений на звук запускайте собранное приложение из Finder.
